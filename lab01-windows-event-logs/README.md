**Objective**
Analyze Windows login events (Event ID 4624/4625) to detect and document a simulated brute force attack pattern on Windows using Windows native tools (Event Viewer) without a SIEM. This lab helps to build the foundational log- reading skills.

**Skills you will gain**
Windows Security Event Log analysis, Event ID interpretation (4624, 4625), Logon Type classification, Status vs. Sub-status code analysis, MITRE ATT&CK mapping, Tier 1 SOC incident documentation
