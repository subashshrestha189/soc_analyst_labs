# SOC Incident Report

**Alert Name:** External Scan followed by Established SQL server sessions with outbound transfer - DB-SRV-01

**Date/Time:** 2026-10-04, 02:14:07 to 02:19:12+ (final session hasn't closed yet)

**Severity:** Critical (pending verification). Suricata signature priority (2) rates the scan, not the incident
  and Suricata's scale is inverted (1 is highest). The severity is driven by a completed session lasting
  for some time (02:14:31 to 02:19:12) with roughly 63 times more data returned to external host than it sent.

**Affected Host:** DB-SRV-01 (10.20.5.15), primary. WEB-SRV-02 (10.20.5.16) was scanned only; no completed
  connection observed.

**Affected User:** Unknown

**Source IP:** 198.51.100.77 (external)

**Destination IP:** 10.20.5.15 (ports 1433, 3306, 5432, 1521); 10.20.5.16 (port 8080)

**Indicators of Compromise:**
  - External IP 198.51.100.77
  - Suricata: ET SCAN alert for MSSQL 1433, MySQL 3306, PostgreSQL 5432, Oracle 1521; local signature LOCAL
    SCAN Possible TCP SYN port scan against 10.20.5.16:8080
  - Zeek: three completed (SF/S1) connections from 198.51.100.77 to 10.20.5.15:1433, the last one for about
    412.3s, state S1 (still open), with 52,110 bytes sent by the source and 3,302,418 bytes returned

**Investigation Findings:** 

Suricata flagged the scan phase. Zeek metadata shows that the only port that accepted connections was 1433
and there was one session where roughly 3.3 MB data was sent from database server to external IP while 
the source sent about 52 KB. Duration alone does not indicate any problem, but the direction and amount of
bytes does. No alert was generated by Suricata on the established 1433 sessions.

Zeek metadata confirms the scan, three session completions to 1433 port, and the data transfer from the
database server.

Hypothesis (not confirmed): a successful SQL login, database content exfiltration, and attacker motive.

**MITRE ATT&CK Mapping:** 

Tactic | Technique | ID |
| :--- | :--- | :--- |
| Reconnaissance  | Gather Victim Host Information: Software | T1592.002 |

**Impact:** 

If the sessions were true, then there is a chance that the data stored in the database was compromised. 

**Recommended Actions:** 
- Escalate immediately to Tier 2 as possible active exfiltration from a database server.
- Block 198.51.100.77 at the perimeter and terminate the open session to 10.20.5.15:1433 (as per the playbook)
- Preserve evidence: Export Suricata eve.json alerts, Zeek conn.log entries and pcap file (if available) before rotation.
- Check 198.51.100.77 against threat intelligence.
- Remove port 1433 from internet exposure and disable any credential confirmed in use.
- Check other hosts for connections attempt from the same source.
- Add detections for external sessions to 1433 and large amount of bytes transferred externally from
  the database server.
  
**Final Conclusion:** 

 The activity is consistent with reconnaissance, followed by an attack on a compromised SQL Server, with a large  
 amount of data being exfiltrated. Login success and data contents are not confirmed yet. Escalation to
 Tier 2 for containment and verification.
